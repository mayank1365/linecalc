It came over LCB/1.

These bytes reached you inside a RESPONSE frame followed by one or more DATA frames, over a single TCP connection that is still open.

The frame header is eight octets: a 24-bit length, an 8-bit type, 8 bits of flags, one reserved bit, and a 23-bit stream id. The wire format is written down in docs/SPEC.md, and every octet of one exchange is annotated in docs/annotated-frame.md.

Try ./bcurl -v localhost:9000/index.html to watch it arrive.
